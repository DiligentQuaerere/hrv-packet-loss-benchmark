# 丢包 → 补间期 → HRV 频域误差实验（EEGMAT）

> 完整报告。根目录 `README.md` 为指针。所有数字由 `src/` 本地脚本算出（`out/run.log`、`out/summarize.log` 为运行日志）。

## 0. 三句话结论（实测）

1. **不补不可用**：5% 成块丢包下不补间期的 HF 中位相对误差已达 ≈1840%（约 18 倍），三种插值都能压到 ≈10%，补间期是必需步骤。
2. **安全区间**：以中位相对误差 ≤10% 为门槛，三种方法对 HF 的安全丢包率均 ≤5%（10% 丢包时跨 10%、20% 丢包时跨 20%）；LF 更脆（5% 丢包即跨 10%）；时域 RMSSD/SDNN 可耐受到 20%。
3. **方法取舍**：M3（均值±1SD 随机）在 10–30% 丢包下 HF/RMSSD 误差最低（保变异性最好）；M1（全局均值）在高丢包下 LF/HF 最稳；M2（左右局部）在 50% 丢包出现灾难性失败（HF 中位 +162%），高丢包不推荐。

网格：67 条保留记录 × 块长 {2,5,10,30} s × 丢包率 {5,10,20,30,50}% × 3 重复 × 4 方法（含不补基线）× 9 指标 = **126,252 行** `results_long.csv`；3,507 次掩码检测记录于 `detection_qc.csv`。

**种子**：`sha256("eegmat-loss-v1|{subject}|{block}|{rate}|{rep}|mask")` 前 8 字节 → `np.random.default_rng`；插值随机流同键但后缀 `|recover`。同受试者两段共用同一种子（配对翻转率需要）。块位置均匀随机、互不重叠、不越界；`n_blocks = round(rate*T/block)`，**圆整为 0 的组合视为不可行并跳过**（如 62 s 记录上 5%×30 s 块：一整块就 48%，无法表示 5%），故各丢包率列 n = 498/699/702/804/804。整数块量化使实际丢包率略偏名义值，逐格记录：实测均值 **6.2 / 11.7 / 18.5 / 32.9 / 49.4%**。

## 3. 管线口径（写死）

- **检测器**：自实现 Pan–Tompkins（5–15 Hz 二阶 Butterworth 零相位 → 五点差分 → 平方 → 150 ms 移动窗积分 → 双阈值自适应 + searchback + T 波斜率判别；不应期 250 ms；定位先 |带通| 极大 ±75 ms、再原始 |x| 吸附 ±30 ms 保证双相 QRS 参考点一致）。全信号与掩码信号用**同一**检测器；`peaks_full` 即真值。与 neurokit2 `pantompkins1985` 交叉核对：Subject00_1 227/229、Subject17_2 105/105 峰在 50 ms 内一致；Subject07_1 上 nk 误标宽 T 波（目视确认我方正确）。
- **信号质量 QC（记录级排除）**：RR<0.30 s 占比 >5%、或 RR>2.0 s 占比 >5%、或平均心率不在 40–160 bpm → 排除。排除 5 条：Subject02_1、Subject13_1、Subject20_2、Subject28_1、Subject35_2（伪迹淹没或系统性双计数，RMSSD 真值 200–350 ms 不合理）。保留 67 条。
- **破坏模型**：删除块内用**线性桥接**填充（块两端样本连线）——端点值连续、无阶跃 → 带通无边缘振铃；块内为慢斜坡 → 检测器漏掉块内全部搏；存活样本零衰减。开发期对比过零填充（含/不含 40 ms 余弦 taper）：零填充在块边缘产生假峰（最坏组合 10–13 个/记录），桥接最坏 ≤4 个。
- **peaks_masked** := 落在删除块**外**的检测峰；块内检测一律视为伪峰丢弃（对所有方法含基线统一）。QC：3,507 次运行共 98 个块内伪峰被丢弃；块外真峰匹配率均值 0.9990。
- **插值**（统一签名 `recover(peaks, gaps, fs, rng)`）：插入峰**桥接**块前最后存活峰 a 与块后第一存活峰 b，个数 `n = floor(块长/RR估计)`，避免边界相位错配跳变（该跳变曾向 HF 注入宽带功率，属实现缺陷而非方法缺陷）。
  - M1 `mean_global`：RR 估计 = 全部完好间期均值；n+1 个等间隔。
  - M2 `mean_local`：RR 估计 = 块左、右紧邻完好间期的均值（缺侧回退全局）；n+1 个等间隔。
  - M3 `random_sd`：n+1 个 RR 抽自 U(均值−SD, 均值+SD)（完好间期统计），按比例缩放至恰好铺满桥接跨度，自 a 累积放置。
  - 基线 `none`：不补，缺口保留为一个长 RR。
  - "完好间期" = 不跨越任何删除块的相邻检测峰间期。
- **HRV**：时域 SDNN/RMSSD（ms）、pNN50（%）。频域：RR  tachogram 三次样条重采样 4 Hz → **生理 clamp [0.3, 2.0] s**（防长缺口样条过冲，真值与估计同用）→ 去均值 → Welch（Hann，nperseg=min(256, N)，50% 重叠）→ 频带边界插值梯形积分；LF 0.04–0.15 Hz、HF 0.15–0.40 Hz、TP=LF+HF；功率 ms²；LFnu/HFnu=带功率/TP×100。
- **频域门槛**：原提示词为 ≥120 s；因 `_2` 压力段全部仅 62 s，**经用户 2026-11-25 确认整体放宽到 ≥60 s**（72 段全过）。62 s 段的 LF 绝对值噪声大，但真值与估计同管线，相对误差内部自洽。
- **误差与判定**：相对误差 =(估计−真值)/真值（真值为 0 或缺失记 NaN；pNN50 真值=0 共 420 行）。summary 含 bias（均值）、bias_median（ signed 中位数）、SD、中位/均值绝对相对误差、方向一致率、翻转率。**均值对离群极敏感，结论一律用中位数**。方向一致率 = sign(估_2−估_1) 与 sign(真_2−真_1) 一致比例；翻转率 = 压力二分判定（LF/HF 升=压力升；HF 降=压力升）用估计值与用真值不一致的比例（31 名双段受试者配对）。
- **阈值**：中位绝对相对误差沿丢包率升序**首次** >10% / >20% 的名义丢包率。

## 5. 失败形状与机制（区分实测与推测）

- 实测：不补 → 全指标巨幅高估；M1/M2 高丢包 HF 低估；M3 高丢包 HF 高估；M2 在 50% 出现长尾崩溃。
- 推测（与实测符号一致的解释）：不补的长 RR 使 tachogram 出现斜坡/clamp 平台 → 宽带功率灌入 LF/HF；M1/M2 常数填充抹掉缺口内的呼吸性窦性心律不齐 → HF 功率随丢包比例流失；M3 的随机 draws 在缺口内注入额外变异性且个数圆整误差随丢包累积 → 高估；M2 的局部边缘 RR 偶不具代表性（过长）→ n=0 缺口未补 → 单格灾难。

## 6. 局限

- 真值 = 统一检测器输出，非专家逐峰标注（Fantasia 验证集未跑，提示词列为可选）。
- 62 s 压力段频域绝对值噪声大（门槛放宽所致）；结论基于同管线相对误差。
- 整数块量化：长块×低丢包组合不可行被跳过；各格实际丢包率见 `summary.csv.loss_actual_mean`。
- 桥接破坏模型是"接收端 concealment"的一种；真实丢包（缺采样而非填值）未模拟。
- 均值偏差列保留但离群敏感；pNN50 真值=0 的 420 行相对误差为 NaN。
